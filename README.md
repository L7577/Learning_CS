# 从零开始-如何学习计算机专业？



数学和英语重要性不言而喻！

高等数学、线性代数、概率论等是先修课程！



## 基础阶段

**程序设计语言**

从一门编程语言开始

**C语言**（必修）

推荐课程

[程序设计入门-c语言-翁恺](https://www.icourse163.org/course/ZJU-199001?from=searchPage)

[C语言程序设计进阶-翁恺](https://www.icourse163.org/course/ZJU-200001)

推荐书籍

- **c primer plus**

- c语言程序设计-K&R



*不要求熟练，至少会简单使用c语言*



---

学习数据结构之前至少掌握一门编程语言

课程

[数据结构-浙江大学](https://www.icourse163.org/course/ZJU-93001)

- 大话数据结构
